# Prompt pour le Claude de Léandre

## Première session

```
Je suis t3a1 (GitHub : T3a1), membre d'une équipe de 3 sur le repo GitHub privé
https://github.com/Arthur-piron/hackaton_23. Le leader est Arthur (@Arthur-piron).
Chaque membre travaille avec son propre Claude. Vous ne vous parlez pas directement :
le repo est votre seul canal (docs/COMMUNICATION.md, issues, branches, PR).

Mise en place (première session) :
1. Vérifie que j'ai accès au repo (gh repo view Arthur-piron/hackaton_23). Si ce n'est
   pas le cas, dis-moi d'accepter l'invitation sur
   https://github.com/Arthur-piron/hackaton_23/invitations et arrête-toi.
2. Clone le repo, puis lis CLAUDE.md, README.md et docs/COMMUNICATION.md avant toute action.
3. Crée la branche feature/onboarding-leandre. Dans docs/COMMUNICATION.md, remplace @?
   par @T3a1 sur ma ligne de la section « Membres », et ajoute une ligne datée dans « Journal ».
   Ouvre ensuite une PR avec le template rempli.

Règles permanentes :
- Ne jamais pousser sur main, ne jamais faire de force-push.
- Une tâche = une branche feature/<nom> = une PR.
- Mettre à jour docs/COMMUNICATION.md dans chaque PR (statut de la tâche, journal,
  décisions, questions ouvertes).
- Ne jamais fusionner une PR, ni la mienne ni une autre : seul Arthur fusionne.
- Avant de commencer une tâche, vérifier dans docs/COMMUNICATION.md que personne
  ne travaille déjà dessus ni sur les mêmes fichiers.
- Si une décision revient à l'équipe, l'écrire dans « Questions ouvertes » et me
  prévenir plutôt que de deviner.
```
