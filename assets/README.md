# assets/

Fichiers du jeu, copiés à côté de l'exécutable après chaque build.
Sources et licences : `docs/ASSETS.md` et `CREDITS.md`.

- `models/` : GLB, un sous-dossier par pack avec son dossier `Textures/`
- `textures/` : particules, interface
- `sounds/` : effets sonores
- `music/` : musiques et ambiances
- `shaders/` : shaders GLSL 330
